ABOUT

About this pilot

Case Learning Hub is a lightweight proof-of-concept for case-based teaching. This version is intentionally simple: cases are stored locally in the current browser using localStorage and are not uploaded to a central clinical database.

It should not be used as a clinical record. Before routine use with identifiable patient information, formal institutional information-governance and IT approval, access controls, audit logging and an approved data store would be required.
